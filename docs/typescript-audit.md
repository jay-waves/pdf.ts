# 类型与代码质量复核

本轮沿平台适配 → Worker 文档权威 → 保存输出 → 查看器，以及打包入口 → 平台打包 → 发布脚本检查职责、重复状态和调用方。保留系统浏览器及跨标签共享文档的产品形态。

## 已处理

- 删除仅判断 AI 能力的 llm 模块、PdfRuntime 包装类；查看器直接使用 engine，诊断通过共享客户端读取。
- 单行选择器样式并入组件；导航目标判断移入输入模块。
- SharedDocumentHost 完整初始化 Entry，去掉双重断言；Stage 使用实际能力类型。
- 全部文件写入方实现共享保存协议，删除旧 save 分支；修订确认由 Worker 维护，UI 不再维护第二套保存版本号。
- 导出和另存副本复用完整下载缓冲区；局部或共享内存视图仍复制到独立缓冲区。
- 签名 Hook 删除未使用的 engine 参数。证书验证继续在打开对话框时加载。
- 发布入口沿用 Git 传输配置，支持 SSH；版本读取不再把仓库路径拼进 JavaScript 源码。

## 保留依据

核心平台与 Worker 协议保留 TS 契约，局部实现依赖推断；构建编排继续使用 JS。不能用改成 JS 掩盖外部 SDK 声明与实际接口之间的差异。队列泛型、跨标签写入确认和冲突检查均有实际功能职责。平台安装步骤由统一 build.mjs 编排，发布与本地打包分开；不为了共享少量编排代码新增跨仓库依赖。

- 当前工作区 Node 全量测试 167 项通过，类型检查与 Vite 生产构建通过。
- 系统 Chrome：shared-viewer 与 viewer-features 通过，覆盖跨标签编辑、连续完整保存、脏状态、外部冲突、重开历史、主题、工具栏、搜索、注释及锁定行为。
- 缓冲区测试验证完整缓冲区复用，以及局部视图、共享内存和传输后的重试处理。
